# Хогвартс: карточная дуэль — первый этап

Это **работающий визуальный прототип сайта**, не полноценная онлайн-игра. Включены 15 карточек из загруженного архива, каталог, поиск, фильтры, просмотр карт и адаптивная главная страница.

## Как запустить через GitHub и Render

1. Распакуйте ZIP.
2. Создайте **новый пустой репозиторий** на GitHub.
3. Выберите **Add file → Upload files** и загрузите **содержимое** распакованной папки (включая `assets`, `index.html`, `cards.json`, `style.css`, `app.js`, `render.yaml`). Сохраните через **Commit changes**.
4. В Render выберите **New → Static Site**, подключите GitHub и выберите этот репозиторий.
5. В настройках: **Build Command** = `echo ready`; **Publish Directory** = `.`. Нажмите **Deploy**.
6. После публикации откройте адрес, который выдаст Render.

## Что ещё НЕ работает

Авторизация, подтверждение аккаунтов, выдача карт по кодам, конструктор колод, бои, наблюдатели, логи и архив — **пока заглушки**. Для этих функций понадобится серверная логика и постоянная база данных (предлагается Supabase), чтобы нельзя было подделать коллекцию или дважды активировать код. Не вводите настоящие пароли на этом прототипе.

## Карты

Исходные изображения переработаны в WebP для быстрой загрузки. Карты перечислены в `cards.json`. Визуальные изображения содержат текст и эффекты; их игровые значения мы отдельно перенесём в базу данных после утверждения правил.
